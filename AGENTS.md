# AI Platform Core Agent Instructions

Before substantial architecture, API, capability, usage, integration, deployment, or production-readiness work, consult `karukimori-wq/ai-development-intelligence`.

Follow `core/autonomous-development-policy.md`: one instruction should advance multiple executable tasks through implementation, verification, fixes, related checks and documentation. Do not stop after a single small task; ask only at a defined stop condition and continue independent authorized work when possible.

Use the task retrieval protocol, ranking/index, and `memory/ai-platform-core/`. For substantial tasks, follow `core/task-run-standard.md` and `core/operational-learning-loop.md`; classify knowledge only after verification and apply strict failure-outcome attribution.

Current AI Platform Core code remains authoritative for implementation; `professional-platform-contracts` remains authoritative for formal platform contracts. Development intelligence is advisory and must be revalidated against current code/contracts.

After meaningful work, evaluate extraction and capture only reusable engineering discoveries, failures/root causes, decisions, patterns, contradictions, or stable evidence. Prefer updating existing knowledge over duplicates.

Never store API keys, prompts containing secrets, tokens, credentials, or personal data in development intelligence.
